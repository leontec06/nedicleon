# Bilder / Photos

Lege deine Fotos hier ab und trage sie dann in `../script.js` in die `photos`-Liste ein:

```js
const photos = [
  { src: "images/zurich-sunset.jpg", alt: "Sonnenuntergang über Zürich" },
  { src: "images/film-portrait.jpg", alt: "Porträt auf Film" },
];
```

- Reihenfolge in der Liste = Reihenfolge im Grid (oben → unten).
- Hoch- und Querformat dürfen frei gemischt werden — nichts wird zugeschnitten.
- Für das Porträt im "About"-Bereich: `PORTRAIT = "images/portrait.jpg"` in `script.js` setzen.
- Tipp: Fotos vor dem Hochladen auf ~2000px lange Kante verkleinern, damit die Seite schnell lädt.
